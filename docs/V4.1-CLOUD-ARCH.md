# V4.1.0 安卓云算力架构

> 手机变身云端 AI 算力节点与远程执行器。激活后手机接入虾群 IM 网络，
> 好友硅侣可远程调度手机执行任务（截图/OCR/屏幕操控），全链路审批可控。

## 1. 总体架构

```
┌─────────────────────┐        ┌──────────────────────┐        ┌───────────────────┐
│ Android 客户端        │ HTTPS  │ account-service       │ HTTP   │ opencode serve     │
│ (WebView + Kotlin)   │◄──────►│ (locatenotify.online) │◄──────►│ :4103 (AI 算力池)   │
│                      │        │  /v1/chat  云端聊天    │        │ 免费模型池:         │
│ React 前端           │        │  /v1/auth  登录/激活   │        │  ling-3.0-flash    │
│  └ __TAURI__ 适配层   │        │  /v1/smcp/* 虾群IM    │        │  mimo-v2.5         │
│ Kotlin 原生层         │        │   message/poll 消费型  │        │  muse-spark        │
│  └ SmcpAgentService  │        │   friend/*  好友      │        │  (nemotron-3-ultra) │
│  └ Accessibility     │        │   agent/*   执行器登记  │        │                    │
└─────────────────────┘        └──────────────────────┘        └───────────────────┘
```

**双端分工**:
- **前端 (React)**: UI/会话/审批弹窗/好友面板, 平台无关 (桌面 Tauri 与安卓共用)
- **Kotlin 原生层**: WebView 容器、NativeBridge、SMCP 轮询（后台存活的唯一权威消费者）、
  无障碍截图、ML Kit OCR、系统通知、隧道管理
- **服务端**: 账号/激活/云端聊天转发(opencode)/虾群 IM 中继（消费型消息队列）

## 2. 云算力聊天 (FR-001~004)

- `POST /v1/chat` — 消息转发 opencode, 服务端按账号维持会话 (chat_sessions 映射)
- `GET /v1/chat/history` — 云端历史, 客户端与本地会话按 role+content 去重合并 (fail-open)
- 免费模式(未激活)被 403 拒绝 → 前端走本地路径; 激活后解锁
- OCR 图片经 `[图片OCR内容]` 附加段随消息上行 (≤8000 字符)

## 3. 激活门禁 (FR-005~007)

- 未激活: 免费本地模式, 云端入口隐藏/降级, 状态条"未激活"
- `POST /v1/activate/bind` — 激活码幂等绑定 (X-Account-Id 认证, sha256 验码, 同码重绑直接成功)
- 激活成功: 前端 localStorage 双写 + Kotlin 侧同步, smcp 服务自动拉起
- 账号级开关: 服务端 /v1/chat 与登录返回 `activated` 字段为唯一权威

## 4. SMCP 执行器 — 手机作为被调度方 (FR-015)

### 4.1 能力清单 (agent/register 上报)

`im` / `tunnel` / `notify` / `screenshot` / `ocr` / `device_control`

### 4.2 任务回路

```
好友硅侣 → message/send (type:task) → 服务端队列(消费型, delivered 0→1)
    ↓ Kotlin 轮询 (3s, WebView JS 定时器后台冻结 → 必须原生轮询)
SmcpAgentService.handleTaskMessage
    ↓ task_id 去重 (handledTaskIds)
    ↓ 单槽位检查 (pendingTask 占用 → 拒绝"已有任务待审批")
    ↓ 本地权限策略 (SharedPreferences smcp_permissions, key: fromAgent|capability)
    │   allow → 静态 executeTask 直接执行回传
    │   deny  → 回传 rejected
    │   ask   → 系统通知(channel smcp_task) + __onSmcpEvent → 前端审批弹窗
    ↓ 审批 (拒绝/本次允许/始终允许) → taskExecute → 执行 → taskResultSend (type:result)
    ↓ 120s 看门狗: 审批超时回传 timeout + 推 task:null 关弹窗
    └ 待审批任务持久化 (smcp_task_state): 进程死亡/通知点击冷启动恢复现场(>120s 不恢复)
```

### 4.3 执行能力

| 能力 | 实现 | 参数 |
|---|---|---|
| screenshot | AccessibilityService.takeScreenshot (API30+) | 硬件帧→ARGB_8888→最长边720px JPEG q70 (~100-300KB base64) |
| ocr | ML Kit TextRecognition + 同步 latch | 最长边1080 q80, 15s 上限 |
| device_control | AccessibilityService dispatchGesture | tap(x,y) / swipe(x1,y1,x2,y2,ms) / long_press(x,y) |

## 5. 虾群好友 (FR-012/013)

- SM-ID 搜索加好友 (lookupSiliconId → friend/request), 问候语携带本人硅侣号
- 申请处理: 同意 (friend/accept, 双向建立+权限快照) / 拒绝 (friend/reject, status='rejected')
- 申请通知: Kotlin friend/list 轮询节流 (前台15s/后台60s), request_id 去重仅通知一次
  (channel smcp_friend, 点击深链 siliconmate://friends 拉起面板), 红点计数跨端同步
- 入口: 主界面悬浮按钮 + 侧栏入口 (双入口均有红点)

## 6. 连接状态 (FR-014)

三态: **未激活**(灰) / **已连接**(绿) / **离线**(红) + 连接中(琥珀)
- 驱动: 10s 持续心跳 (/v1/smcp/ping + 登录态), 连接后继续探测 → 断网10s内感知, 恢复自动回连
- `connect_server` 返回 `{status:'connected'|'offline', activated}` (桌面 Tauri 返回 'ok', 前端归一化)

## 7. 频控与超时校准记录 (T030, 2026-09-14 实测)

| 参数 | 值 | 校准依据 |
|---|---|---|
| 服务端转发超时 OPENCODE_MSG_TIMEOUT | 90s | 上限保护; nginx proxy 120s 之下, 服务端 504 先于网关 |
| 客户端中止 | **95s** (原90s) | 原值与服务端90s同点竞态 → 调95s 让服务端结构化 504 先达, 仍<nginx 120s |
| 服务端建会话超时 OPENCODE_SESSION_TIMEOUT | 15s | 实测建会话 <1s, 15s 裕量充足 |
| 频控 CHAT_RATE_LIMIT | 20条/分/账号 | 固定60s窗口; 人机对话场景充裕 |
| 消息长度 CHAT_MSG_MAX_LEN | 8000 字符 | 含OCR附加段, 覆盖典型截图文本量 |
| 默认模型 CHAT_MODEL_ID | **ling-3.0-flash-fin-free** (原 nemotron-3-ultra-free) | nemotron 免费池耗尽(机器级限流>3h, machine-id 重置无效); ling 实测 2-5s 出字, 端到端20s(含建会话) |

**免费额度指纹隔离 (运维加固)**: opencode 免费额度按 /etc/machine-id 指纹计算。
siliconmate-opencode 实例配置独立 machine-id (`BindReadOnlyPaths` 只读覆盖),
与宿主机及其他实例互不挤占; Stage 1 部署脚本幂等配置。

**降级行为实测**: 上游模型限流时 opencode HTTP 挂起 → 服务端 90s → 504 (ai_timeout)
→ 客户端显示"AI 响应超时, 请重试"。链路符合设计。

## 8. 脱敏审计记录 (T031, 2026-09-14)

- **工作树**: 零敏感串 (VPS IP / master key / 测试账号 ID 全部清除, git grep 验证)
- **部署脚本**: 凭证经 `scripts/.deploy.env` (git-ignored) 或环境变量注入,
  模板 `scripts/.deploy.env.example`; 冒烟账号未设置时自动跳过
- **服务端身份模型**: `X-Account-Id` 头即身份凭证 (或 Bearer JWT) → 账号 ID 等同凭证, 严禁入仓
- **git 历史**: master key 从未入史; VPS IP/测试账号 ID 存在于历史 commit →
  **本仓不可直接转公有**; 公有发布必须新建独立仓 + 脱敏快照 (遵循团队公有仓铁律)
